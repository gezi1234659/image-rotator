# image-rotator
一个简单的图片旋转工具，可以将一个文件夹中的图片旋转特定的角度并且输出

1. **准备图片**  
   找到包含需要旋转图片的文件夹

2. **启动程序**  
   双击运行 `rotate_images.exe` 文件

3. **设置输入路径**  
   ```
   请输入图片文件夹路径 [默认: 当前文件夹]:
   ```
   - 直接按 Enter 使用默认路径
   - 或输入自定义路径后按 Enter

4. **设置旋转角度**  
   ```
   请输入旋转角度 (0-360):
   ```
   - 输入数字后按 Enter

5. **设置输出路径**  
   ```
   请输入输出文件夹路径 [默认: ./out]:
   ```
   - 直接按 Enter 使用默认输出文件夹
   - 输入文件夹名称在当前目录创建子文件夹
   - 输入完整路径保存到其他位置

6. **确认设置**  
   仔细核对显示的信息是否正确

7. **开始处理**  
   输入 `y` 后按 Enter 开始旋转图片

8. **完成操作**  
   处理完成后按 Enter 退出程序

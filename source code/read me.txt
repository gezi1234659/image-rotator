支持格式'.jpg', '.jpeg', '.png', '.bmp', '.tiff', '.webp'
但是我只测试了.png和.jpg的图片，别的格式的图片手里没有

打包:nuitka
安装好这个库pip install nuitka（记得配置好环境变量，我这里卡了好久，不过也可以用python -m nuitka来搞）
检查下是否安装成功，配置环境成功，运行nuitka --version，如果跳出版本说明好了
（python -m nuitka --version可以但上一个不行说明环境变量没配好）
先找到这个.py文件，然后在命令行（我用的是anaconda prompt）中转到文件所在位置
然后再在命令行运行nuitka rotate_images.py --standalone --onefile
rotate_images.py是要打包的程序名，--standalone是把解释器打包进去，让他能在无python环境运行，--onefile是生成一个exe文件

我本来试图做成自动检测.exe文件所在位置然后处理这个文件所在文件夹的所有图片的方式，但是经过测试发现当前工作文件夹为C:\Users\gezi\AppData\Local\Temp\ONEFIL~1，不是exe文件所在文件夹，所以我放弃了这个想法，改为手动输入图片所在文件夹和输出文件夹（默认为当前文件夹）
但是这时如果你使用默认输入（当前文件夹）就又正常了，可以识别文件夹为当前文件夹了，我之后再研究研究
